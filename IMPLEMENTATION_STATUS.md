In-memory, per-process cache for external answers (`apps/api/src/utils/ttlCache.ts`; no Redis or other store): a validated Mode A forecast is reused for an identical request for 15 minutes, at most 16 kept (`AI_FORECAST_CACHE_SECONDS`, default 900); a DCD pair's FX reference rate for 1 hour (`FX_RATE_CACHE_SECONDS`, default 3600); fan-chart history already had a 1-hour cache.
